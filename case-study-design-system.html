The handoff problem

Teams ship beautiful Figma libraries that never match production. Renamed tokens partial variants close enough CSS drift compounds every sprint. Engineers stop trusting design files. Designers stop trusting Storybook.

Designer + Developer insight: I realized the problem isnt skill its that two people interpret the same spec differently. The fix make one person responsible for both sides.

Design-Dev GapToken DriftHandoff Friction

Stage 1: Figma Variables + Token Architecture

Design work: Created Figma variables for colour space radius and type. Every component variant was named to become the Angular @Input prop name.

Developer thinking: Named tokens to map directly to CSS custom properties. No translation layer needed.

Figma VariablesDesign TokensAuto-layout

Stage 2: Style Dictionary Export

Pipeline engineering: Token Studio exported a single tokens.json into Style Dictionary via CI. This generated CSS custom properties and TypeScript types automatically.

Key decision: Humans never edit variables.css directly. Every change starts in Figma making the design file the single source of truth.

Style DictionaryCI/CDSingle Source of Truth

Stage 3: Angular Components

Development work: Built standalone Angular components in a shared package. Each components props exactly match the Figma property names.

Button component: 4 variants x 3 sizes loading state disabled state ARIA support. All driven by the same tokens that started in Figma.

Angular StandaloneARIAComponent API

Stage 4: Storybook Living Docs

Full-circle: Stories mirror Figma component paths exactly. Controls expose the same props designers specified in Figma. The docs tab copies production-ready code snippets.

Engineers can inspect any components status Ready / Partial / Not started and know exactly whats safe to use in production.

// Core Discipline

THE ONE RULE:
NAMES NEVER CHANGE

The single most important decision in this pipeline if Figma has color/primary/900 CSS has --color-primary-900 and the Angular component references the same token. Button props like variant size disabled loading match Figma properties exactly.

This one discipline eliminated the most common source of design-dev drift entirely.
